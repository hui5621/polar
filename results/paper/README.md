# Experiment results

This directory contains CSV files with route-planning experiment results.

- `nine_metrics_12dates_5seeds.csv`: Nine route metrics for twelve scenes, five seeds, and ten methods.
- `SIACO_ablation_5seeds_nine_metrics.csv`: S-IACO ablation results for three scenes and five seeds.
- `DRL_ablation_3scenes_5seeds_nine_metrics.csv`: DRL ablation results for three scenes and five seeds.

Columns include scene date, random seed, method, nine result metrics, and their corresponding standard-deviation fields.
